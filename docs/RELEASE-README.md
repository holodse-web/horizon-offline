# HORIZON OFFLINE · by RRM Network

[Русская версия](README.ru.md)

Minecraft on Rust, playable with a cracked installation too. No Microsoft/Mojang sign-in.

1. Extract this ZIP to a writable folder.
2. Keep `horizon-offline.exe` and `horizon-launcher.exe` together.
3. Run `horizon-offline.exe`. Set a nickname with **2**, then press **1 / Enter**.

Requires installed **Minecraft Java 26.3** and **JDK 25+** for first setup.
Use **4** to select your Minecraft/TLauncher folder if needed.
First resource setup needs internet and can take several minutes; then you can play offline.
New program/launcher versions are installed automatically at startup.

**Use English in the game. Russian works poorly and can load very slowly.**
