# HORIZON OFFLINE · by RRM Network

[English version](README.md)

Minecraft на Rust, который можно запустить и на пиратке. Вход в Microsoft/Mojang не нужен.

1. Распакуй ZIP в папку с правом записи.
2. Оставь `horizon-offline.exe` и `horizon-launcher.exe` рядом.
3. Запусти `horizon-offline.exe`. Задай ник через **2**, затем нажми **1 / Enter**.

Нужны установленная **Minecraft Java 26.3** и **JDK 25+** для первой подготовки.
Если Minecraft/TLauncher не найден, укажи его папку через **4**.
Первая подготовка ресурсов требует интернет и занимает несколько минут; потом можно играть офлайн.
Новые версии программы и лаунчера устанавливаются автоматически при запуске.

**Играй на English: на русском игра работает плохо и может загружаться очень долго.**
