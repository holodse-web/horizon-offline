# HORIZON OFFLINE

[English version](README.md)

<img src="assets/horizon-offline.png" alt="Horizon Offline" width="96">

**by RRM Network** · v0.7.2 · Windows x64 · Minecraft Java 26.3

Неофициальный терминальный лаунчер для нативного Rust-клиента
[Horizon](https://github.com/horizon-rust/horizon). Офлайн-ник, импорт настроек
существующего Minecraft и обновление с заменой только изменённых файлов.
Меню лаунчера — на русском.

**[Скачать последнюю версию](https://github.com/holodse-web/horizon-offline/releases/latest)**

> [!WARNING]
> **Рекомендуется играть на английском.** На русском языке игра сейчас работает
> очень плохо и может загружаться очень долго. Выбирай **English** в настройках игры.
> Это касается языка самой игры; меню лаунчера можно оставить на русском.

## Запуск

1. Скачай **`Horizon-Offline-0.7.2.zip`** из Releases и распакуй в папку с правом
   записи. Оставь `horizon-offline.exe` и `horizon-launcher.exe` рядом.
2. Нужна собственная установленная **Minecraft Java 26.3**. Сначала запусти её
   обычным лаунчером, чтобы необходимые файлы были скачаны.
3. Открой **`horizon-offline.exe`**. Если автопоиск не сработал, укажи папку
   `.minecraft` или папку игры TLauncher через пункт **4**.
4. Задай ник в пункте **2** и нажми **1** или **Enter**.

При первом запуске скачивается Horizon и готовятся ресурсы из существующих
файлов Minecraft. Подготовка занимает несколько минут; Java-экспортёрам нужен
**JDK 25+**. Если он не находится автоматически, укажи JDK в `JAVA_HOME`.
После подготовки нативную Rust-игру можно запускать без интернета.
Для установки и проверки обновлений интернет нужен.
Моды Java/Fabric в формате JAR этот нативный клиент не поддерживает.

## Меню

| Кнопка | Действие |
|---|---|
| **1 / Enter** | Играть |
| **2** | Сменить ник: 3–16 латинских букв, цифр или `_` |
| **3** | Проверить клиент и ресурсы |
| **4** | Указать папку существующего Minecraft; пустой путь — автопоиск |
| **5** | Открыть папку игры |
| **6** | Установить Horizon или проверить обновления |
| **7** | Импортировать настройки Minecraft |
| **0 / Q** | Выйти |

Из `options.txt` выбранного Minecraft импортируются язык, клавиши, звук,
графика и другие параметры, которые поддерживает Horizon. При первом запуске
настройки импортируются автоматически, если у Horizon ещё нет своих.
Повторный импорт — пункт **7**; предыдущий файл сохраняется в
`game/.options-backups/`. Исходный Minecraft не изменяется.
**Язык тоже переносится:** выбери English до импорта или смени его уже в игре.

## Обновления и данные

Если версия уже актуальна, появляется **«Уже обновлено»**, без повторной установки.
Загрузкой релиза и проверкой его подписи занимается оригинальный
`horizon-launcher.exe`.

Заменяются только изменённые файлы, добавляются недостающие. Совпавшие файлы
остаются на месте. Удаляются только устаревшие файлы из списка предыдущей установки;
остальные пользовательские файлы сохраняются. **Архив upstream-релиза пока
скачивается целиком**; установка на диске выполняется по изменённым файлам.
Совместимые подготовленные ресурсы используются повторно. Если их формат
изменился, старые сохраняются в резервной копии перед подготовкой новых.
При ошибке применения обновления восстанавливается предыдущая версия.

Данные находятся в **`Horizon Offline Data/`** рядом с EXE:

- `game/` — миры, настройки, скриншоты и логи игры;
- `versions/` — установленный клиент и подготовленные ресурсы;
- `.rust-updates/` — журнал и резервные копии изменённых файлов.

Ник и путь Minecraft сохраняются в `horizon-rust.json`, ошибки запуска — в
`horizon-offline.log`. Существующая папка **`Horizon Rust Data/`** подхватывается
автоматически. Личные данные и результаты сборки исключены из Git.

## Сборка из исходников

Нужен **Rust 1.86+**, набор инструментов Windows x64 и соответствующий линкер.
В **PowerShell** из папки проекта:

```powershell
.\Build.ps1
```

Для встраивания иконки нужен `rc.exe` из Windows SDK при сборке MSVC либо
`windres.exe` из MinGW-w64 при сборке GNU. Путь можно задать в `RC`.
Скрипт запускает тесты, собирает EXE и проверяет меню в изолированных папках,
без запуска игры. Исходники находятся в `src/`; полный исходный проект Horizon
для этой сборки не нужен.

В репозитории размещены исходники. Для запуска своей сборки положи оригинальный
**`horizon-launcher.exe`** из архива релиза рядом с `horizon-offline.exe`.
Для готовой установки скачивай наш ZIP из Releases, а не автоматически
созданные GitHub архивы **Source code**.
