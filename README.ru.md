# HORIZON OFFLINE

[English version](README.md)

<img src="assets/horizon-offline.png" alt="Horizon Offline" width="96">

**Minecraft на Rust, который можно запустить и на пиратке.**

Horizon Offline от **RRM Network** запускает [Horizon](https://github.com/horizon-rust/horizon)
с файлами уже установленного Minecraft — в том числе из стороннего лаунчера,
например TLauncher. Для запуска через нашу программу вход в Microsoft/Mojang не нужен.

**[Скачать для Windows x64](https://github.com/holodse-web/horizon-offline/releases/latest)** · v0.8.0 · Minecraft Java 26.3

> [!WARNING]
> **Рекомендуется играть на английском.** На русском игра сейчас работает плохо
> и может загружаться очень долго. Выбирай **English**.

## Как играть

1. Скачай **Horizon-Offline-0.8.0.zip** из Releases и распакуй архив.
2. Оставь **horizon-offline.exe** и **horizon-launcher.exe** в одной папке с правом записи.
3. Запусти **horizon-offline.exe**, задай ник через **2** и нажми **1 / Enter**.

Нужны установленная **Minecraft Java 26.3** и **JDK 25+** для первой подготовки
ресурсов. Если Minecraft не найден, укажи его папку через **4**. Если JDK не найден,
задай `JAVA_HOME`. Первая подготовка требует интернет и занимает несколько минут;
после неё можно играть офлайн. Файлы самого Minecraft в архив не входят.
Моды Java/Fabric в формате JAR не поддерживаются.

## Что умеет программа

- При запуске проверяет GitHub и устанавливает новые версии **Horizon Offline**,
  **официального лаунчера Horizon** и уже установленного **игрового клиента Horizon**.
  После обновления нашей программы она перезапускается сама. Без интернета остаётся
  доступна установленная игра. **8** — повторить обновление программы и лаунчера;
  **6** — установить или обновить игровой клиент.
- Скачивает полный архив обновления, но на диске заменяет только изменённые файлы
  клиента. Совместимые готовые ресурсы используются повторно. Если обновлений нет —
  сообщает, что всё уже обновлено.
- При первом запуске переносит настройки Minecraft, если у Horizon ещё нет своих.
  **7** — повторный импорт с резервной копией. **Язык тоже переносится — выбирай English.**
- Показывает прогресс загрузки и подготовку ресурсов; логотип коротко анимируется при старте.

**Остальные кнопки:** **2** ник · **3** проверка файлов · **4** папка Minecraft ·
**5** папка игры · **0 / Q** выход. Меню — на русском.

## Где лежат данные

Рядом с EXE, в **Horizon Offline Data/**. Старая папка **Horizon Rust Data/**
подхватывается автоматически. Миры и настройки — в `game/`, ник и путь Minecraft —
в `horizon-rust.json`. Обновления их сохраняют. Резервные копии программы — в
`.horizon-updates/`, клиента — в `.rust-updates/` внутри папки данных.
Перед обновлением закрой другие окна лаунчера.

`--no-update` пропускает автоматические обновления на один запуск, `--updates-check`
только проверяет версии программ. `HORIZON_OFFLINE_NO_ANIMATION=1` отключает движение;
также учитывается настройка анимаций Windows.

## Сборка и авторы

Нужны **Rust 1.86+**, линкер Windows x64 и `rc.exe` из Windows SDK (MSVC) либо
`windres.exe` из MinGW-w64 (GNU). В **PowerShell** запусти `./Build.ps1`.
Скрипт проверяет и собирает программу без запуска игры. Положи рядом оригинальный
`horizon-launcher.exe` из релиза. Архивы исходников не являются готовой сборкой.
